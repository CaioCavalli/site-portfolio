Gestão de Saúde Corporativa

Description

I worked as a PHP developer (PHP 7) and data analyst, enhancing an existing production project. I designed the MySQL database schema and developed routines for collecting, processing, and storing clinical data. From these data, I defined eligibility rules and parameterized queries by “competência” (reporting period) to generate preventive-health alerts. Result: a preventive-care module that identifies active patients who meet the criteria, produces protocol-specific overdue lists, and supports triggering preventive-care communications. On the front end, I used Bootstrap and jQuery to display filterable/searchable lists, making it easier to prioritize and communicate with eligible patients—without changing the existing visual identity.
